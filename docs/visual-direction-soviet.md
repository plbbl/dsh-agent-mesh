# DSH Agent Mesh · Soviet Cold War visual direction

This is an original modern-product translation of the Soviet Cold War
`BUILDING-SYSTEM / STRUCTURED-SYSTEM` mechanism. It borrows the communication
grammar of public construction, education, and infrastructure posters; it is
not a reproduction of a historical poster.

- Branch / period: `BUILDING-SYSTEM`, 1965–1982 institutional / public-system tone.
- Audience: developers and DSH users.
- Social promise: several local coding executors can work through one stable DSH conversation.
- Layout: `FOCUS-SYSTEM`; the system silhouette is the main subject, with a compact functional text field.
- Visual thesis: “把本机多个 coding CLI 接进一个正在工作的 DSH 公共系统。”
- Canvas: vertical 3:4; keep a 5% safe border and reserve the upper-left 35% for exact copy.
- System silhouette: five offset horizontal platforms, three vertical supports, one restrained connection line, and small worker/tool markers for scale.
- Foundation: blue-grey terrain and a lower road/water line, showing the control plane as infrastructure rather than a dashboard.
- Palette: aged paper `#E7D3A9`, print black `#11151C`, science blue `#163B72`, cold blue `#2E6C9E`, action red `#D9342B`, ochre `#E9B83F`.
- Typography / exact copy: `把多个 / coding CLI / 接进一个 / DSH 对话`; the same sentence is used on the social-card cover.
- Print treatment: hard flat shapes, limited offset colors, fine paper pattern, small registration-like misalignment; no gradients or glossy light.
- Prohibited drift: no random stars, hammer-and-sickle emblems, Lenin portrait, wartime mobilization, neon cyberpunk, glass office towers, UI card grids, or fake microtext.
- Thumbnail test: at 25% scale, the red `coding CLI` line and the stacked blue system must read within one second.
