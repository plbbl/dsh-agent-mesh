# Changelog

All notable changes to DSH Agent Mesh are documented here.

## [0.1.0] - 2026-08-15

### Added

- DSH-native host plugin with local harness discovery and persistent sessions.
- Composite `harness · model` selector in DSH's existing model seat.
- Codex, Claude Code, ACP, Pi RPC, and experimental ZCode adapters.
- Durable cross-session messages, structured handoffs, bounded automatic routing,
  no-turn doctor checks, and credential-safe discovery.
- Recovery for interrupted OMP prompts and stale native OMP sessions.
